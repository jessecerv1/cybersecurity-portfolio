Jesse Cervantes - Cybersecurity student. This repo tracks hands-on projects built while studying penetration testing, network security, and secure development.

## Projects

### Web Recon Tool
A Flask-based reconnaissance tool with an AI-generated findings summary. Given a target URL, it pulls HTTP headers, checks robots.txt/sitemap, scans for common exposed files and admin paths, and feeds the findings to an LLM to summarize results and suggest next steps for a pentester.

**Tech:** Python, Flask, BeautifulSoup, OpenAI API
**Repo:** [web-recon-tool](https://github.com/jessecerv1/web-recon-tool)
